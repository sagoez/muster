# muster-protocol

An internal crate of [muster](https://github.com/sagoez/muster), the supervisor and control plane behind your terminal: what its service, holders and clients exchange, from the wire DTOs and framed IPC to the service protocol and the process log format. It has no stable API and is published only so `muster-workspace` can be installed from crates.io. To use muster, run `cargo install muster-workspace`.
