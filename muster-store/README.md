# muster-store

An internal crate of [muster](https://github.com/sagoez/muster), the supervisor and control plane behind your terminal: its SQLite store of projects, stacks, settings, coordination and run history, with the migrations that move it forward. It has no stable API and is published only so `muster-workspace` can be installed from crates.io. To use muster, run `cargo install muster-workspace`.
