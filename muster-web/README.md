# muster-web

An internal crate of [muster](https://github.com/sagoez/muster), the supervisor and control plane behind your terminal: `muster view`, a live, read-only page of every project's processes served on loopback. It has no stable API and is published only so `muster-workspace` can be installed from crates.io. To use muster, run `cargo install muster-workspace`.
