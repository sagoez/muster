# muster-os

An internal crate of [muster](https://github.com/sagoez/muster), the supervisor and control plane behind your terminal: its unix helpers for private state and socket directories, process groups and signals, detached spawns and bounded reads. It has no stable API and is published only so `muster-workspace` can be installed from crates.io. To use muster, run `cargo install muster-workspace`.
